AoE IV 本机对局分析工具
适配版本：17.0.12182.0，Windows x64

运行
1. 启动已适配版本的游戏，进入本机单人测试对局。
2. 双击 dist\AoE4LocalLab.exe。程序自动连接并检查游戏文件 SHA-256。
3. 切回游戏，单位名称会以玩家大厅所选颜色显示在对应世界位置。
4. Alt+Tab 回到面板，可更改采样间隔、字号、玩家筛选以及是否包括建筑或中立实体。
5. 修改采样间隔或字号后点击“应用”。点击“停止读取”会停止采集并隐藏标签。
6. 关闭面板即退出。导出按钮可将当前筛选快照保存为 JSON 或 CSV。

采样与显示
采样间隔范围：20–2000 ms，默认 100 ms。
相机与标签约 30 Hz 刷新；实体成员列表约每 500 ms 更新，玩家颜色约每秒更新。
标签使用鼠标穿透窗口，只有游戏处于前台时才显示；窗口失焦、最小化或读取失败时隐藏。
建议使用窗口化或无边框模式。独占全屏、多显示器切换和非标准视角未完成全面验证。
标签点表示实体世界坐标投影，文字通过连线错开以减少重叠。
密集单位仍可能产生拥挤，可减少字号或按玩家筛选。

名称与范围
“真实蓝图名称”直接来自游戏内存。默认名称是常见类型的显示别名，不是完整游戏本地化表。
点击“单位名称配置”，可像表格一样逐行修改名称；也可双击主列表中的单位直接打开该蓝图配置。
双击“自定义名称”或“备注”单元格编辑，Enter / Tab 完成编辑并跳到下一行。
点击“保存并应用”后，画面标签、主列表和快照中的 display_name 立即使用自定义名称。
清空自定义名称后保存即可恢复默认；未配置别名的类型显示真实蓝图名称。
可以切换“完整蓝图名称”模式核对原始标识；保存配置会自动切回“自定义 / 默认名称”。

Excel 批量配置
1. 在“单位名称配置”里点“导出 CSV”。文件使用带 BOM 的 UTF-8，支持中文。
2. 用 Excel 打开，保留“蓝图名称”列不变，编辑“自定义名称”和“备注”。
3. CSV 列为：蓝图名称、默认名称、自定义名称、备注。“默认名称”仅作参考，不参与覆盖。
4. 保存为 CSV，在程序内“导入 CSV”，检查暂存结果后点击“保存并应用”。
5. 导入按蓝图合并，不删除其他行；导入行的空自定义名称表示恢复默认。重复蓝图或错误列会拒绝整次导入。
6. 如需预先配置尚未出现的兵种，可点击“新增蓝图”输入准确蓝图名称，或在 CSV 中加入新行再导入。

名称按完整蓝图精确匹配，不使用模糊匹配。
队友和对手的同一蓝图共用名称；不同文明、不同等级若蓝图不同，可以分别命名。
程序自动记住对局中遇到的新单位类型；配置窗口中的“收集当前对局”可刷新当前列表。
配置保存在 程序所在目录\config\unit_names.json，重启程序、更新 EXE 和切换对局后保留。
错误配置文件会保留，不会被默认表静默覆盖。外部修改文件后请关闭并重新打开程序。

枚举范围
默认包括双方玩家所属单位、建筑、归属玩家的牲畜。中立实体可选。
实体类型识别目前依据 unit_ / building_ / gaia_ 蓝图前缀。
“世界实体总数”还包括武器等辅助对象，因此通常大于标签数量。
进入驻军、运输、死亡过渡等状态的实体尚未单独验证；标签以实体表提供的位置为准。
读取并不按本地视野过滤，迷雾外对象也会进入列表；不在当前镜头范围内的对象不画屏幕标签。

实现与限制
只使用 OpenProcess(PROCESS_QUERY_INFORMATION | PROCESS_VM_READ)、ReadProcessMemory 等读取接口。
不向游戏内存写入，不注入模块，不修改游戏文件，不调用游戏内部函数。
仅支持当前已验证构建。版本 SHA-256 不匹配时拒绝读取，不能沿用偏移到更新版本。
文件哈希：4c99b868cbec98b2219e135908a31d03c64c7b71f2bbcf1469dab1d7c6df2c9f
当前验证环境是本机单人对局；多人模式、其他文明组合与大规模后期对局未全面验证。
采样不是游戏线程提供的原子快照；会检查容器与实体 ID，但瞬时状态仍可能跨模拟帧。

诊断
配置和滚动日志位于 程序所在目录\config\。
界面显示异常时，查看 lab.log；游戏退出或切换对局时程序会隐藏标签并尝试重新连接。
本机已安装 Python 3.12，也可运行 python app.py；应用运行无需第三方 Python 库。
research.py 是适配研究脚本，使用 vendor 中的 Capstone；不属于运行程序的必需依赖。
运行测试：python -m unittest test_lab.py test_unit_names.py

便携存储：配置、设置和日志均位于 EXE 同级 config 文件夹。上传或迁移时请复制整个程序文件夹。源码运行时使用 app.py 同级 config。
