# 游玩辅助实机适配状态（2026-11-02，v1.1.0-preview.1）

适配游戏 17.0.12182.0，继续保留 reader.py 的 SHA-256 校验。当前测试环境为本机单人：P1 红色金帐汗国，P2 绿色日本 AI。

## 已接入及验证

- 本机玩家：从 Game_GetLocalPlayerID 的真实客户端身份读取；本局内部 ID 1007 映射 P1，不猜最低槽位或颜色。
- 屏蔽自己：界面实测列表 100 → 85 个实体；只过滤本机所属实体，独立中立实体开关继续生效。统计面板不受名单筛选影响。
- 断农提醒：两座城镇中心分别读取生产扩展与订单。实测红方队列 0 → 1 → 0，训练后人口 6 → 8，再次训练后 8 → 10；本文明一条订单生产两个农民，villager_count 表示订单数。空队列持续 2 秒出现覆盖层 tips，15 秒重复，恢复生产清除提示。可选择已识别的任意玩家。
- 人口：读取当前人口、当前容量（含玩家属性修改）、最终上限。红方容量/上限 200/200，与游戏 HUD 相符；绿方容量由 20 随建房增至 40。人口提醒依据现人口距离容量 ≤5，30 秒冷却；容量达到最终上限不提示。本局红方因此未出现造房提示。
- 分数：读取游戏状态模型的 total_score、military_score、economy_score、society_score、technology_score。右侧面板显示并按总分降序。红方实测总分 83 → 103，经济 70 → 90，军事 13；与新增两个农民的变化对应。绿方随 AI 游戏持续更新。
- 军事统计：存活实体的游戏 military 类型标记，排除死亡实体，农民和渔船不计入，侦察兵计入。ArmyValue 来自游戏统计管理器的当前军队资源向量求和，军事人口来自同一管理器的累计统计。两方一名侦察兵时分别为军数 1、军值 65、军事人口 1。军事占比采用军事人口/现人口，避免多人口兵种的数量与人口混淆。
- 敌我关系：从游戏外交矩阵读取，本局红绿为敌对。军情提醒已接入真实军数、军值、军事分数，严格超过 25/50/100 时每局每玩家每档提醒一次。
- 界面底部此前可能被挤出，已压缩实体列表最小行数。覆盖层分数、军事面板及断农 tips 已观察到在游戏窗口内显示。

## 验证边界与未完成项

- 自动造农：决策器已有，执行器未接通，复选框禁用。上述农民订单测试通过普通游戏界面人工式点击完成，不能作为自动造农已实现的证据。
- 受袭撤离：决策器已有，实际威胁、指令来源（尤其主动攻击例外）、可达安全目的地与避难容量尚未全部验证；复选框禁用，不发送撤离命令。
- 尚未实际触发敌军 26/51/101 个单位的场景，也未在本机玩家未达最终人口上限时触发近满人口场景。阈值、冷却、未知数据与抑制规则目前由自动化测试覆盖，不能称为全部实机通过。
- 未验证所有文明、多人队友、自建多个城镇中心、所有生产队列项目（科技等）、存档读取及换局。遇到未知生产项目返回未知，不冒充空队列。统计管理器与模拟实体可能有短暂更新时差。
- queued_population 暂时未知；人口提示按现人口工作，不预测还未计入现人口的排队需求。
- 提醒是本程序的透明覆盖层，不修改游戏原生 UI。所有游戏内存访问保持只读，无注入或内部函数调用。

## 测试与构建

`python -m unittest discover -s source -p 'test_*.py'`：45 项通过，包含名称配置、投影、提醒规则及合成内存的边界/未知项目/树损坏测试。合成测试不冒充实机数据。

本局约 1600 个世界实体、100 个左右标签候选时，运行面板显示整体采样中位数约 1.2 ms（硬件及局势相关）；辅助采集一次测得约 0.6 ms。刷新间隔继续支持 20–2000 ms，相机约 30 Hz。

本地预览：`preview/AoE4LocalLab-preview.exe`；独立配置：`preview/config`。对应 GitHub 预发布版本 `v1.1.0-preview.1`，便携包包含预览配置快照。根目录 v1.0.0 EXE 及原 GitHub Release 保留。

## 给后续 AI 的接口线索

所有地址均为当前哈希版本的模块 RVA 或对象内偏移，不能跨版本照搬：

- 本机身份：Game_GetLocalPlayerID 0xB6CBE0，模块+0x7CE9DA8 → +0x330 → 玩家 ID +0x154。
- 队列：生产扩展 getter 0x1F483E0；扩展+0x54 指向模拟队列数据，+0x40 数组偏移、+0x44 数量，订单步长 0x90。只接受已核对的类型/蓝图 getter。
- 人口：Player_GetCurrentPopulation 0x1A3B050；容量 0x1EECA60，属性修改 0x2215630、0x2214190。
- 类型标记：Entity_IsOfType 0x1A9D7E0；存活判定 Entity_IsAlive 0x1A9DB60。
- 状态字典：0x3726240 返回模块+0x885C190，浮点注册表+0x708、类型注册表+0xA8；按名称查找索引，不固定语言相关显示名。
- 分数状态：Player_GetStateModelFloat 0x1A3D080 → 0x80A4E0；模拟玩家+0x308 的状态模型。
- ArmyValue UI getter 0x128F020；统计管理器由本机客户端+0x238 的包装对象取得，vtable RVA 0x63E79A0；玩家树+0xB0，每节点键玩家 ID +0x20、值+0x28。统计值+0x2C4 为资源向量，+0x734 为军事人口。
- 统计更新 0x960100 与移除 0x96888C 可继续追踪分类/资源口径；不要以军事分数×常数替代军值。

最终预览补充验证：新版画面已显示 P1 军值 65、现人口 22、军事人口 1、占比 4.5%；P2 军值 65、现人口 38、军事人口 1、占比 2.6%。同时 P2 军事分数为 33，说明军值并未由军事分数简单换算。

最终连续采样：100/100 有效，未出现辅助字段错误，中位数 1.69 ms、P95 6.05 ms。此前在实体新增过程中遇到过实体表一致性校验失败，读取器丢弃该帧并自行恢复；不能据此声称整个实机过程零瞬态重试。
